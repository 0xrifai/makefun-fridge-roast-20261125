A make.fun entry for [Fridge Roast: One Line, Biggest Laugh](https://make.fun/bounty/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb) — one line, at most 200 characters, roasting a smart fridge.

## The line

> I said 'crushed ice' and it queued a true-crime documentary. My fridge thinks I'm a detective.

The angle: the fridge's voice assistant mishears a simple request and confidently does the wrong thing — no grocery-ordering, no watching-you, no firmware-update ice-maker joke. The punchline lands on the last clause: the fridge doesn't just fail, it forms an opinion about you.

## How it runs

`main.ts` writes the line to the absolute path `/output/entry.txt` (Node 22 runs TypeScript as-is):

```sh
node main.ts
cat /output/entry.txt
```
